# FastAPI Gestión de Empleados

Este proyecto es una aplicación de gestión de empleados construida con FastAPI. Permite a los usuarios gestionar información básica sobre empleados, incluyendo la creación, lectura, actualización y eliminación de registros.

## Características

- CRUD (Crear, Leer, Actualizar, Eliminar) para empleados
- Validación de datos
- API RESTful
- Documentación automática de la API

## Tecnologías Usadas

- [Python](https://www.python.org/)
- [FastAPI](https://fastapi.tiangolo.com/)
- [SQLAlchemy](https://www.sqlalchemy.org/)
- [SQLite](https://www.sqlite.org/index.html) (u otra base de datos según configuración)
- [Pydantic](https://pydantic-docs.helpmanual.io/)
